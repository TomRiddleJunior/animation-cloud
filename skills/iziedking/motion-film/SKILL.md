# Motion film

A film made the way software is made: a brief that becomes a shot list, shots built on the engine that suits them, a finish that unifies them, and a QC report that proves the export. The same source renders the same film.

This skill covers many looks and many tools. It does not have a house style. The look comes from the brief and the references, and the engine is chosen per shot.

## Read first, in this order

1. `references/process.md`: the gates. Always.
2. `references/toolchain.md`: what is installed, what to install, which engine for which shot, licence catches. Run `node templates/tools/doctor.cjs` before promising anything.
3. Only the references the job needs (table below). Do not load them all.

## The non-negotiables

1. **Approval gates.** Brief, then reference study, then directions, then script and shot list, then a 6 to 8 second motion study at final finish, then the full build. Never render the full film before the study is approved.
2. **Offer real choices.** Two to four directions that differ on at least two of: palette, texture, depth (flat, 2.5D, 3D), type, camera, source type. Three variations of one look is one direction. Use `references/style-atlas.md`.
3. **Truth boundaries.** Every claim on screen is true today, visibly labelled ("Illustration", "Planned", "Testnet", "Example figures", "Dramatisation"), or cut. No invented customers, metrics, testimonials, partner logos or prices. No AI person presented as a real customer, employee or expert.
4. **Brand pixels are real.** Logos, product UI, packaging, prices, legal text and on-screen copy come from the client's real assets and are composited. They are never generated by an image or video model.
5. **Every shot has a source type and a licence.** Authored (code or 3D), real capture, client footage, stock, or generated. Each asset gets a row in `provenance.json` with its source, tool, licence and terms URL. No row, no place in the film. Non-commercial and unknown licences are refused for commercial work. See `references/legal-provenance.md`.
6. **Spend and accounts need a yes.** Before any paid API call or cloud render, show the estimated cost and wait for approval. Never create an account, accept a licence agreement or enter a key on the user's behalf; ask them to.
7. **Study, never copy.** A reference is studied for structure, pacing, devices and finish, then rebuilt with original assets. No reference pixels, music or artwork in the export. See `references/reference-study.md`.
8. **Deterministic time.** Every authored shot is a pure function of the frame index. No wall clock, no unseeded randomness, no real-time recording as the master. Render frames, then encode; never render straight to a video file.
9. **Voice.** A real recorded voice by default. A synthetic voice only with approval and a recorded licence; a cloned or imitated real voice only with that person's written consent on file. Captions are taken from the delivered audio.
10. **Continuity and readable holds.** Each cut carries an object, a motion or a sound across it. After every material statement, hold about 0.3 s per word and never under 1.2 s.
11. **Measure, then look.** Deliver `qc.json`, `audio-qc.txt`, contact sheet and transition strips. A film is done when QC passes and the frames have been looked at, not when the encode finishes.
12. **Know the machine.** Time one frame before committing to a render. Under 3 GB of free memory, or with no GPU for a GPU job, render remotely or in a bounded container, one render at a time.

## Choosing the engine for a shot

| The shot is | Engine | Reference |
|---|---|---|
| Flat or textured vector, diagrams, type, simple UI | Canvas template in `templates/` | `engines-2d.md` |
| Real HTML/CSS UI, glass, CSS 3D tilt, kinetic type with GSAP | DOM capture (own loop or HyperFrames) | `engines-2d.md` |
| Many variants from data, or a React team | Remotion (state its licence first) | `engines-2d.md` |
| Maths, algorithms, charts | Manim CE, or D3 driven by frame index | `engines-2d.md` |
| Gradient fields, grain, liquid, halftone, glow backdrops | Fragment shader layer | `engines-2d.md` |
| Hand-drawn, boiled line, paper and collage, character | Canvas or p5 with seeded jitter and textures | `engines-2d.md`, `style-atlas.md` |
| A Lottie or Rive file from a designer | Seek it frame by frame | `engines-2d.md` |
| Hero product, real materials, glass, metal, coins, macro, sims | Blender (Cycles) headless | `engines-3d.md` |
| Light 3D inside a 2D film: device tilt, cards in depth, particles | three.js in the capture loop | `engines-3d.md` |
| A walkthrough of a live app or site | Scripted capture plus virtual camera | `product-demo.md` |
| Existing footage: event sizzle, gameplay, interviews, listicles | FFmpeg edit from a cut list | `live-action-edit.md` |
| Atmosphere, environments, impossible or abstract b-roll | Generated image, then image-to-video | `generative.md` |
| People | Client footage or released stock first; generated only as a labelled illustration | `generative.md`, `legal-provenance.md` |

Most films mix engines. The Arcle-style fintech ad is a canvas or DOM film with three 3D inserts (tilted icon tiles, coins, a rendered landscape plate). Build each shot where it is cheapest to do well, then unify them in the finish.

## Starting a film

```bash
node templates/tools/doctor.cjs                    # what this machine can do
node templates/tools/refstudy.cjs ref.mp4          # shot list, contact sheets, palette, loudness of a reference
```

Copy `templates/` into a new working folder. For a canvas film:

```bash
npm install && npx playwright install chromium
node render.cjs proof       # stills at the times in film.config.json
node render.cjs study       # the motion study window
node render.cjs render      # silent master, sound bed, mixed master
node render.cjs qc          # measured checks and contact sheets
```

Other starting points: `templates/capture/` (any HTML page that exposes `window.renderFrame(i)`), `templates/blender/` (headless product shots), `templates/edit/` (cut-list editing of footage), `templates/finish/` (grade, grain, masters, platform encodes), `templates/provenance/` (the asset ledger).

## When to stop and ask

- The brief has no truth boundary for a claim the script needs.
- A reference would have to be copied, or the request names a living artist's style, a celebrity, or a third party's character or mark.
- Anything costs money, needs an account, or needs a licence the user has not confirmed.
- A real person's face or voice would be generated, cloned or imitated.
- The machine cannot render the job in the time available: say the measured time per frame and offer the options in `toolchain.md`.
- A tool the plan relies on is missing and cannot be installed from the command line.
